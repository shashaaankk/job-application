# Jetson
The thesis target was a Jetson AGX Orin 64GB, running the multithreaded perception and language pipeline described in [[Master Thesis]].

Scope limit that matters. The Orin runs full L4T and Ubuntu, so this is application work on a Linux board and is NOT evidence of embedded Linux platform engineering. There is no Yocto, no BSP and no cross-compilation work behind it. A device label never upgrades into a discipline claim.
